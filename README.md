<h1>Kitsune Theme for Steam</h1>

A personal fork of [SpaceTheme/Steam](https://github.com/SpaceTheme/Steam). Same look, but the code that blocked plugins like LuaTools, manilua and lumea has been removed, so they work normally.

## Install
1. Install [Millennium](https://docs.steambrew.app/users/installing).
2. Add this theme to your Millennium themes, then pick "Kitsune Theme for Steam" in Millennium settings.
3. Restart Steam.

## What is different from SpaceTheme
- The plugin-blocking code is removed, so LuaTools, manilua and lumea work.
- Renamed to "Kitsune Theme" in the titlebar and settings.
- Everything else follows SpaceTheme upstream.
